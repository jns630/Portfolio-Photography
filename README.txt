JAW PHOTOGRAPHY — PORTFOLIO WEBSITE
===================================

HOW TO VIEW
1. Extract this ZIP to a folder.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
3. The site and photos work locally. Google Fonts are an optional online enhancement; local fallback fonts are included in the CSS.

BEFORE PUBLISHING
- Open index.html in a text editor.
- Find YOUR_EMAIL_HERE and replace it with the email address you want visitors to contact.
- Optional: change the JAW brand text and About copy to suit your preferred public name.
- All gallery images included in assets/ are photographs you previously shared in ChatGPT. The site does not use stock photography.

FEATURES
- Responsive editorial portfolio design for desktop and mobile.
- Category filters: after dark, nature, city/forms, and light studies.
- Full-screen image viewer with next/previous navigation and Escape-key support.
- No build process, framework, paid service, or tracking script required.

PUBLISHING
The folder can be uploaded to any static site host that serves HTML/CSS/JS and local image assets. Keep the assets folder beside index.html.
